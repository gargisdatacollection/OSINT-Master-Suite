Tools & Workflow Overview – Seth Gargis
1. OSINT Pipeline Overview
My OSINT pipeline is a modular, automated suite that performs:

Username enumeration

Email intelligence

Phone footprinting

Domain reconnaissance

Metadata extraction

Case folder creation

Summary generation

Each module can run independently or as part of a structured workflow.
